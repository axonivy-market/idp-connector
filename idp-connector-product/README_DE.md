# Axon Ivy IDP Connector

Axon Ivy IDP verbindet dein System mit einer Intelligent Document Processing (IDP)-Lösung, die das Aufteilen, die Klassifizierung und die Extraktion von Daten aus unstrukturierten Dokumenten automatisiert. So reduzierst du manuelle Arbeit in dokumentenintensiven Prozessen wie Rechnungsverarbeitung, Schadenbearbeitung und Kunden-Onboarding.

### Wichtigste Funktionen
- Automatisiere das Auftrennen und die Datenerfassung von Dokumenten, um manuelle Arbeit zu reduzieren.
- Nutze fertige Workflows (Rechnungsextraktion, generelles Splitting) für gängige Anwendungsfälle.
- Die integrierte Validierung markiert unsichere Extraktionsergebnisse, damit du weniger Fehler manuell prüfst.
- Eingebettete Viewer-Komponente: Vorschau, Speichern und Teilen von Dokumenten direkt im Prozess.
- Sichere Anbindung per API-Key und flexible REST-Konfiguration.
- Liefere mehrere Ausgabeformate (PDF, Miniaturansichten, OCR-Text, Seitenbilder und Sub-PDFs).
